# A Una Milla - Backend API

Backend API for the A Una Milla travel hack platform.

## Features
- **Duffel Flight Search Integration**: Real-time airline flight searches (multi-slice & single-slice) via Duffel Air API.
- **Card Catalog & Valuations**: Indian credit card reward engine database schema and routes.
- **User Wallet Management**: Endpoints for managing user cards, points balances, and category spending habits.
- **Supabase PostgreSQL & RLS**: Secure Row Level Security per-user queries.

## Running Locally

```bash
npm run dev
```

Runs on `http://localhost:3001`.
